## Default Permission

Default permissions for FrogLight mobile vault storage

#### This default permission set includes the following:

- `allow-pick-folder`
- `allow-forget-folder`
- `allow-list-folders`
- `allow-read-dir`
- `allow-stat`
- `allow-read-file`
- `allow-write-file`
- `allow-mkdir`
- `allow-remove-file`
- `allow-remove-dir`
- `allow-rename`
